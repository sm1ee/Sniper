The working set

Inspect. Replay.
Keep the context.

The everyday tools for understanding an application, together in one workspace.

Capture & inspect
Read HTTP and HTTPS history alongside WebSocket traffic. Scope filters and a site map help you focus.
Intercept & replay
Pause a request, make an edit, and send it on. Return to captured requests to compare how your application responds.
Keep the context
Separate work into sessions, each with its own records, scope and state, saved on your machine.
Review findings
Passive checks flag potential issues in captured traffic, including sensitive data and security-header configuration.
Use the small tools
Decode, encode, hash and inspect JWTs without leaving the app. Payload-based testing is available in Fuzzer.
Work from a terminal

Sniper + your coding agent

Ask AI about
your traffic.

Claude Code or Codex can use Sniper’s captured requests as context. The agent runs separately and reads your local session through the bundled sniper-cli, which returns structured JSON.

Claude Code setup ↗Codex setup ↗
  1. 01

    Capture your test traffic

    Open Sniper and browse an application you own or have permission to test. Keep Sniper running so the agent can read the captured requests in your session.

  2. 02

    Add the optional Sniper skill

    Set up Claude Code or Codex separately, including its sign-in. Make sniper-cli available in your terminal, then follow the integration guide to install sniper-operator. The skill adds instructions; it does not install or sign in an AI app.

  3. 03

    Ask about a captured request

    Try: “Summarize failed requests in this session and explain one response I choose.” The agent uses the CLI to list captures and read selected request and response details, then helps you explain the behavior or draft a debugging note.

Check what you share.

Sessions are saved on your machine, but records an external agent reads enter its context and may reach its model provider or transcripts. Captures can contain cookies, tokens and personal data; Sniper does not automatically redact them. Use a dedicated session with test data suitable for sharing.

Make yourself at home

Get Sniper.

Pick your platform. Release files and their SHA-256 checksums are published on GitHub.

macOS

Apple silicon + Intel

Install with Homebrew. The cask also puts the bundled sniper-cli on your PATH.

brew install --cask sm1ee/tap/sniper

Or choose the universal .dmg from the latest release and drag Sniper into Applications.

macOS release files ↗

The app is ad-hoc signed, not notarized. macOS may require you to allow it in System Settings → Privacy & Security → Open Anyway.

Windows

Windows 10 / 11 · x64

Choose the -setup.exe installer for a per-user installation, or extract the entire portable .zip and open sniper-desktop.exe.

The desktop app requires WebView2 Evergreen Runtime and the Microsoft Visual C++ v14 Redistributable. These are not bundled.
